# Fictional bibliography review

Regenerate with `npm run example`.

- `bibliography.bib`: five invented records, source notes and a string macro; original CRLF preserved.
- `project.json`: source and portable review settings, initially unreviewed.
- `candidates.csv`: all three independent groups.
- `report.json`: complete machine-readable scan and review.
- `review.html`: escaped standalone review packet with all original source.
- `summary.svg`: actual generated summary, not a workspace screenshot.

`river2024` and `RIVER2024` collide as keys despite different titles. `river2024` and `gardenCopy` have matching synthetic DOI values. Those two plus `notes` share a normalized title and year. `unique` is uninvolved.

No publications or identifiers are verified; these examples are not reference data.
